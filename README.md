# منصة عبء العمل

صفحة واحدة تجمع ثلاث خدمات لتحليل عبء العمل والاحتياج الوظيفي، ويختار المستخدم ما يريد منها:

| الخدمة | المسار | ماذا تفعل |
|---|---|---|
| تحليل عبء العمل (الإصدار 1) | `apps/analysis/` | إدخال المهام الفعلية وحساب الاحتياج والفجوة لكل مسمى فعلي، مع مساعد ذكي وتصدير Excel بمعادلات حية |
| تحليل عبء العمل حسب الأقسام (الإصدار 2) | `apps/sections/` | كالإصدار 1 مع الأقسام / الوحدات، والاحتياج لكل قسم × مسمى |
| محرك نماذج عبء العمل | `apps/engine/` | توليد نموذج مهام افتراضي من عدد الموظفين المستهدف |

## التشغيل
- **على الإنترنت:** بعد النشر على GitHub Pages يُفتح الرابط مباشرة.
- **محليًا:** افتح `index.html`. للتجربة الكاملة يُفضّل خادم محلي:
  ```bash
  py -m http.server 8000
  ```
  ثم افتح `http://localhost:8000`.

## الروابط المباشرة
- `index.html#analysis`: تحليل عبء العمل
- `index.html#sections`: التحليل حسب الأقسام
- `index.html#engine`: محرك النماذج

يمكن أيضًا فتح أي خدمة منفردة عبر `apps/<الخدمة>/index.html`.

## البنية
```
index.html          ← الصفحة الرئيسية (اختيار الخدمة والتنقل بينها)
apps/
  analysis/         ← الإصدار 1
  sections/         ← الإصدار 2 (الأقسام)
  engine/           ← محرك النماذج
```

- كل خدمة مستقلة بملفاتها (الخط ومكتبة ExcelJS محفوظان محليًا داخلها)، فالمنصة تعمل دون أي اعتماد على مواقع خارجية.
- الصفحة الرئيسية تعرض الخدمات داخل إطارات تبقى محمّلة، فالتنقل بين الخدمات لا يضيّع البيانات المُدخلة.
- هذه نسخة النشر فقط.

## الخصوصية
- كل الحسابات تتم داخل المتصفح، ولا تُحفظ بيانات الجهات على أي خادم.
- المساعد الذكي (في خدمتي التحليل) متوقف افتراضيًا. عند تفعيله بمفتاح API خاص بالمستخدم تُرسل نصوص المهام إلى المزوّد المختار فقط، والمفتاح يُحفظ في متصفح المستخدم.
